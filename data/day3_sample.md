# Day 3 切分测试文档

## 第一部分：普通文本

人工智能正在改变世界。文本切分是构建检索增强生成系统（RAG）的重要一步。如果我们切分得太碎，可能会丢失上下文；如果切分得太大，可能会超过模型的上下文窗口限制。因此，我们需要合理设置 chunk_size 和 overlap。

## 第二部分：代码块测试

下面是一段 Python 代码，用来演示切分器是否会切断代码块：

```python
def add_numbers(a, b):
    """
    这是一个简单的加法函数
    """
    result = a + b
    return result
print(add_numbers(3, 5))
```
如果切分器在 `return` 和 `result` 之间剪了一刀，这段代码在检索出来时就是残破的。

## 第四部分：问答对测试

Q: 什么是文本切分？
A: 文本切分是把长文本切成小块（chunk）的过程。

Q: 为什么要设置 overlap？
A: overlap 是为了让相邻的 chunk 之间有重叠内容，避免上下文在边界处丢失。

Q: 什么是零宽断言？
A: 零宽断言是正则表达式中只匹配位置、不消耗字符的语法，常用于切分边界处理。
