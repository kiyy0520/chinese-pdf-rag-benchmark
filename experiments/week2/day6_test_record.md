## 二、错误案例（3 条）

### 案例 1：检索漏召（问题 5）

- **问题**：根据课件，强化学习与监督/无监督学习最直观的区别是什么？
- **系统回答**：根据提供的资料无法回答。
- **ground_truth**：监督/无监督学习使用的是 Fixed Data（固定数据），而强化学习是 Agent 与 Dynamic Environment（动态环境）进行交互。
- **实际检索到的 contexts**：全部是 MDP 五元组、占用度量、值迭代、课程大纲等片段，**完全没有命中包含 "Fixed Data" / "Dynamic Environment" 的那一页**。
- **判断**：这是典型的**检索漏召**。原始 PDF 中确实存在这段对比文字（ground_truth 已确认），但检索模块没有把它召回。原因是该段内容篇幅短、语义特征不强，被 MDP 相关的高频片段挤占了 top-k 位置。
- **影响指标**：Faithfulness 0.33（答不出内容，只能回答"无法回答"）、Context Precision 0.00（召回片段全部无关）。
- **改进方向**：
  1. 增大 `n_results`（如从 3 调到 5），给短小关键段落更多入场机会。
  2. 引入 **重排序（Rerank）**，用交叉编码器对候选片段重新打分。
  3. 对 chunk 做 **元数据过滤**，让检索能按 PDF 页/章节聚焦。

### 案例 2：轻度幻觉（问题 6）

- **问题**：什么是占用度量（Occupancy Measure）？
- **系统回答**：给出公式后，额外补充了一段解释："即：在策略 π 下，从初始状态分布出发，与动态环境交互过程中，状态-动作对 (s, a) 在折扣时间步上的期望访问频次（或概率质量）。"
- **ground_truth**：占用度量公式为：ρ^π(s,a) = E_{a~π(s),s'~p(s,a)}[∑_{t=0}^T γ^t p(s_t = s, a_t = a)]
- **判断**：额外补充的这句"期望访问频次（或概率质量）"原文里并没有直接表述，属于 LLM 基于常识的**自行扩展解释**。内容大体正确，但不完全来源于检索片段，属于**轻度幻觉**。
- **影响指标**：Faithfulness 0.60。
- **改进方向**：
  1. Prompt 里明确要求"每个论断必须能在参考资料中找到原句支撑，否则不要写"。
  2. 让模型在答案中标注引用编号，便于追溯。

### 案例 3：过度解释 / 轻度幻觉（问题 9）

- **问题**：价值函数的 Bellman 等式是什么？
- **系统回答**：给出两个公式后，额外逐项解释了 `R(s)`、`γ`、`P_s^{π(s)}(s')` 的含义，并说"求和项表示下一状态的期望价值"。
- **ground_truth**：V^π(s) = R(s) + γ ∑_{s∈S} P_{sπ(s)}(s') V^π(s')
- **判断**：额外的变量解释部分，在检索到的 contexts 中并没有逐条列出，属于 LLM 的**自主扩展**。虽然内容正确，但严格来说不算"完全忠实于上下文"。
- **影响指标**：Faithfulness 0.75。
- **改进方向**：
  1. Prompt 增加"只回答被问到的内容，不要主动展开解释"。
  2. 对公式型问题单独设计 Prompt 模板，只要求返回公式。

## 三、结论与改进方向

### 主要问题类型
1. **检索漏召**：短小关键段落容易被高频章节挤掉（问题 5）。
2. **轻度幻觉 / 过度解释**：LLM 会对公式自行展开解释，虽然内容大体对，但不完全来源于检索片段（问题 6、9）。
3. **PDF 解析噪声**：contexts 中大量出现 `\uf070`、`\u0dcd` 等乱码字符，说明 PDF 解析阶段有符号未正确还原，影响 embedding 质量。

### 改进优先级
1. **短期**：增大 `n_results` 到 5，Prompt 加"仅引用原文"约束。
2. **中期**：加入 Rerank（BGE-reranker），对候选片段二次排序。
3. **长期**：优化 PDF 解析（替换 pypdf 为 pymupdf 或 unstructured），清洗乱码字符后再切分。
